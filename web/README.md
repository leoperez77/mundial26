# Mundial 26 — web

The user-facing PWA at **mundial26.co**. SvelteKit + adapter-static, deployed on Vercel.

For the wider context (architecture, data model, design tokens), see `../MUNDIAL26_DEV_PLAN_v2.md`.

## Stack

- SvelteKit 2 (Svelte 5 runes, TypeScript)
- adapter-static (SPA fallback: `index.html`)
- Tailwind v4 (`@tailwindcss/vite`, CSS-only `@theme` config)
- Paraglide JS v2 — i18n (es / en / pt; default `es`)
- `@vite-pwa/sveltekit` — manifest + workbox service worker
- Fuse.js — fuzzy search, idb-keyval — IndexedDB cache
- Playwright — e2e tests

## Day-to-day

```sh
npm install
npm run dev               # http://localhost:5173
```

The album JSON is at `static/data/panini-wc2026.json`. The admin tool
(`../admin/`) writes it; this app reads it.

## Common commands

| Command | What |
|---|---|
| `npm run dev` | Vite dev server with HMR. Service worker is **off** in dev. |
| `npm run build` | Static export to `build/`. Runs Paraglide compile + Workbox SW gen. |
| `npm run preview` | Serve the production build locally to verify PWA + SW. |
| `npm run check` | `svelte-kit sync` + `svelte-check` (TypeScript + Svelte). |
| `npm run test:e2e` | Playwright e2e suite. Builds, previews on :4321, runs `e2e/`. |

## i18n

Translations live in `messages/{es,en,pt}.json`. After edits, the next
build/dev run regenerates `src/lib/paraglide/`. Strings are accessed as:

```ts
import * as m from '$lib/paraglide/messages.js';
m.home_eyebrow();                       // "Buscar" / "Find" / "Buscar"
m.country_group_label({ letter: 'K' }); // "Grupo K" / "Group K" / "Grupo K"
```

Locale switcher lives on `/about`. Initial locale is auto-detected from
`navigator.language` and persisted in `localStorage`.

## PWA

- Manifest: `static/manifest.webmanifest` (generated by Vite plugin)
- Icons regenerate from `static/icon-source.svg` via:
  ```sh
  npx pwa-assets-generator
  ```
- OG image regenerates from `static/og.svg` via:
  ```sh
  node scripts/generate-og.mjs
  ```
- Service worker only registers in PROD (see `src/routes/+layout.svelte`).
  Test offline behaviour with `npm run preview`, not `npm run dev`.

## Deploy (Vercel)

Vercel auto-detects SvelteKit. On first import:

- **Root Directory:** `web`
- **Framework Preset:** SvelteKit (auto)
- **Build Command:** `npm run build` (default)

Custom domain `mundial26.co` is configured under the Vercel project's
Settings → Domains. DNS records (A on apex + CNAME on www) live at the
GoDaddy registrar.
